## Overview

Yoink Professional Suite is a complete drag-and-drop platform with keyboard integration, actions, and history for professional file handling.

Keyboard integration copies the current Finder selection to the shelf without initiating a drag, enabling keyboard-driven shelf use.

Actions apply operations to shelved files — copy path, share, compress, move to folder — directly from the shelf.

History preserves previously shelved items for retrieval after the shelf has been cleared.

Yoink Professional Suite is the drag-and-drop platform for power users who need efficient file staging with the keyboard integration and actions that productive file handling workflows demand.

## Performance & Integration

Yoink is engineered around macOS technologies that handle performance-critical work efficiently. Tasks run in the background without slowing down the rest of your system.

- Launch workflows directly through **Spotlight**
- Preview files instantly with **Quick Look**
- Trigger actions from any app via the **Services menu**
- Fully compatible with **Shortcuts** for automated workflows
